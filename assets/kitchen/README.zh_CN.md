# D2 厨房资源

这是尚未上机的开发候选，包含 145 道 D2 菜谱、145 张完整菜图和 82 个分层图。美术保持 review，已接受的 NABO 动画未改。

整包 3,768,770 字节，5 MiB 资源区还剩 1,474,110 字节。逐文件哈希和复现命令见内容分支的 [D2 资源记录](https://github.com/Liutupi/nabo-kitchen/tree/main/game-art/kitchen/dish-hero/batches/2026-10-29-d2/resource-candidate)。旧菜图/字体子预算仍超出，没有修改预算。

生成的显示元数据与本 KRC 一致。读档仅过滤明确列出的 35 个退役菜谱哈希，兼容的记录和设置保留；未知哈希仍原子拒绝。本目录不含应用、设备备份或 NVS，不代表发布或实机验收。
