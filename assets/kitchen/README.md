# D2 kitchen resources

This unflashed development candidate contains 145 D2 recipes, 145 complete dish illustrations and 82 compositing layers. Art remains under review. The existing accepted NABO animation is unchanged.

The bundle is 3,768,770 bytes; 1,474,110 bytes remain in the 5 MiB resource partition. Precise payload hashes and reproducible commands are in the content branch's [D2 resource record](https://github.com/Liutupi/nabo-kitchen/tree/main/game-art/kitchen/dish-hero/batches/2026-10-29-d2/resource-candidate). The historical dish/font sub-budgets remain exceeded and have not been changed.

The paired generated metadata matches this KRC. Save migration drops only the 35 explicitly retired recipe hashes, retaining compatible records and settings. Unknown hashes still reject the input atomically. This directory contains no application, device backup, or NVS. No release or device acceptance is implied.

Source font licenses are retained in `licenses/OFL.SourceHanSans.txt` and `licenses/OFL.ArchivoBlack.txt`. Project art and recipe licensing remains separate from the source-code MIT license.
