# NABO 深夜厨房 v0.2.0 · 体验版

- 更新 D2 菜谱质量版：现有 145 道菜，替换/补齐 36 张新菜图，完整菜图无缺失。
- 去掉日期确认、日期设置和无效时钟；最近做过的菜按完成做饭的次数降权。
- 抽签计数持久保存，上次菜单跨重启保留，重抽不限次；等级与小结只按做菜次数统计。
- 选中项整块变为暖橙色，文字保持深色，选择更明显。
- 首页新增常驻“计时器”，离开菜谱后也能重新进入并暂停、继续或取消。
- 兼容记录迁移到新版存档，过滤退役菜引用；已验应用与资源原样打包。
- 尚未完成三道实际下厨验收，按体验版发布；菜谱与美术仍在审校。

下载完整固件或 ZIP 分段包，完整安装可能重置设置和记录；保留数据升级见[安装说明](https://github.com/Liutupi/nabo-kitchen/blob/v0.2.0/docs/community/v0.2.0/installation.zh_CN.md)。

构建与宿主门禁通过；有限设备读回、启动、计时导航及用户首页入口确认通过。本版未完成三道实厨、完整合并镜像再次首装及全部美术/硬件验收。应用保留已验 0.2.0-dev 构建字节，未为版本标签重编。[精确产物与验证范围](https://github.com/Liutupi/nabo-kitchen/blob/v0.2.0/docs/community/v0.2.0/release-validation.json)。
