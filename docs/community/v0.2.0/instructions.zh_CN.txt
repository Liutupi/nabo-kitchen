1. 安装前确认现有记录可重置：社区“安装最新版”使用完整镜像，可能清空原设置与厨房记录。需要保留已有兼容厨房数据时，请先阅读 GitHub v0.2.0 安装说明，使用分段升级。
2. 开机后短按 OK 进入厨房，不需要配网或确认日期。上下键移动选择，短按 OK 进入或切换；快速双击上键返回上一页，长按上键直接回首页。
3. “今天吃什么”里选择人数、可用时间与荤素组合，选“颠勺”得到菜单。首页长按 OK 可使用记住的条件直接抽菜。结果页下键不限次换菜，OK 看用料，长按 OK 收藏。
4. 用料页下键加入买菜单，长按下键翻动长清单，OK 开始跟做。步骤页 OK 前进、上键回上一步；长文字短按下键先滚动，到底后再按进入计时器；长按下键看用料。
5. 带计时的步骤第一次 OK 开始计时，下一次 OK 前进，计时仍在后台运行。回到首页后，选底部“计时器”并按 OK 就能重新进入；默认首页位置短按上键一次也能选到它。
6. 计时页上下键选择项目，长按 OK 暂停/继续，长按下键取消选中项，快速双击上键返回；到时短按 OK 确认。运行中断电后恢复为暂停，需要重新确认。取消计时不会删除做菜步骤。
7. “冰箱”先选分类再按 OK 选食材，长按 OK 看推荐；买菜单可勾选已买，图鉴可查看收藏与做菜记录。“设置”可调声音、音量、忌口、口味偏好和难度。
8. 最近做过的菜只降低推荐权重，仍可能再次抽到；这里按做饭次数记录，不按天数。份量、火候与熟度请结合实际食材和厨具判断，菜谱及插画仍在校对中。
