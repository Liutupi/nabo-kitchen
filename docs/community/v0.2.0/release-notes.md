# NABO Midnight Kitchen v0.2.0 · Experience prerelease

- D2 recipe quality update: 145 recipes, with 36 new or replacement dish illustrations and no missing complete dish images.
- Removed date confirmation/settings and invalid clock placeholders. Recency now follows completed cooking sessions.
- Persisted draw counter and menu across reboots, unlimited redraws, and count-based levels and summaries.
- Whole-card warm-orange selection with dark text for clearer navigation.
- Permanent home Timers entry to reopen, pause, resume or cancel timers after leaving a recipe.
- Compatible records migrate to the new save format with retired dish references removed. The accepted application and resources are packaged unchanged.
- Acceptance through three actual cooking sessions remains incomplete; this is an experience prerelease with recipes and artwork under review.

Download the complete firmware or the ZIP of separate images. Complete installation may reset settings and records; see the [installation guide](https://github.com/Liutupi/nabo-kitchen/blob/v0.2.0/docs/community/v0.2.0/installation.md) for a compatible data-preserving upgrade.

Build and host checks passed, with limited device write/readback, boots, timer navigation and user-confirmed home entry. Three actual cooking sessions, another first installation of this merged image and full art/hardware acceptance remain incomplete. The accepted 0.2.0-dev application is retained byte-for-byte rather than rebuilt for the release tag. [Exact artifacts and validation scope](https://github.com/Liutupi/nabo-kitchen/blob/v0.2.0/docs/community/v0.2.0/release-validation.json).
