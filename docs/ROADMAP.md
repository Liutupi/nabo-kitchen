## 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 模式 B 内存不够 | 不能边做边说话 | v0.1 不依赖它；M4 先做验证；不行就降级成只有步骤卡片 |
| files 分区已被占用或文件系统不合适 | 用户菜谱和记录没地方存 | M4 开工前先核实；备选方案见 ARCHITECTURE 5.2 |
| assets 预算超支 | 素材放不下 | 按 ARCHITECTURE 5.3 的顺序减 |
| 分层合成的菜像“贴纸” | 不够精致 | A1 样板屏里就要验证合成效果；加汤汁底和高光层；招牌菜用精绘图补 |
| 计时铃在厨房听不见 | 菜烧糊 | 真机在油烟机旁实测；铃声频段和重复次数可以调 |
| 菜谱缺字 | 屏幕显示方块 | 打包时检查；用户菜谱写入前检查 |
