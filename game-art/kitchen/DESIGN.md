# NABO 深夜厨房 · 玩法与界面设计

架构见 [../../docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)，美术见 [ART_BRIEF.md](ART_BRIEF.md)。线框图在 `reference/wireframes.png`，每页对应下文的编号。

## 1. 一句话

深夜小巷里有一间只有一个吧台的小店，NABO 是店主。你坐在吧台前问他“今天吃什么”，他颠一下锅，端出一道菜，再一步一步教你回家做出来。

**故事设定**：NABO 白天是医生，下了夜班，就在巷子口开这间只营业到深夜的小厨房，做的都是家常菜。

## 2. 体验原则

1. **三秒出结果**：开机进厨房，按一次 OK 就有菜。不强制先设条件，条件记住上一次的设置。
2. **手上有油也能用**：跟做页的字要大，翻页只按 OK；计时到了，声音和画面一起提醒。
3. **不打扰**：NABO 的小动作只在等待的时候出现，不挡住步骤文字。
4. **天天打开都有一点新东西**：今日签、图鉴进度、偶尔出现的彩蛋台词。

## 3. 页面流程

```
封面 P0 ──OK──▶ 吧台首页 P1
                 ├─ 今天吃什么 ─▶ 条件 P2（可跳过）─▶ 颠勺 P3 ─▶ 结果 P4 ─OK─▶ 用料 P5 ─OK─▶ 跟做 P6 ⇄ 计时 P7 ─完成─▶ 上菜 P8
                 ├─ 冰箱里有啥 ─▶ 选食材 P9 ─▶ 推荐列表 P10 ─▶ 结果 P4
                 ├─ 买菜单 ───▶ 清单 P11
                 ├─ 我的菜谱 ─▶ 图鉴 P12 ─▶ 结果 P4
                 └─ 设置 ─────▶ P13
```

计时器在后台独立运行。在任何页面，计时到了都会弹出顶部横条，按 OK 跳到计时页 P7。

## 4. 各页面

### P0 封面（240×320，约 1.2 秒，按任意键跳过）

雨后的小巷夜景，一间小店的门口挂着暖帘，帘子上只有 NABO 心电线的标志，**不写店名**。灯笼亮起，暖帘被风吹起一下，接着进入 P1。

### P1 吧台首页

- 上部场景 240×196：店内是暖光吊灯和背后的木架（摆着调料瓶，不画任何品牌）。NABO 站在吧台后擦碗（`idle`）。吧台木沿的上边缘就是锚点线。
- 左上角：当前时间，用小号文楷，营造“深夜营业”的感觉。右上角：计时器图标和剩余时间（有计时器在跑时才显示）。
- 下部是 124 px 高的菜单木牌：一屏显示 4 项，第 5 项需要滚动；单行高 24 px，当前项亮灯，用 UP 和 DOWN 选择。
  1. 今天吃什么
  2. 冰箱里有啥
  3. 买菜单（有几项就显示数字）
  4. 我的菜谱（显示图鉴进度，例如 23/300）
  5. 设置
- 今天还没抽过时，“今天吃什么”旁边有一个小灯笼在闪。
- 超过 30 秒没有操作，NABO 打瞌睡（`doze`）；按任意键醒来。

### P2 条件（纸菜单样式）

三行选项，UP 和 DOWN 选行，OK 切换取值：

| 行 | 取值 |
|---|---|
| 吃几个人 | 1 / 2 / 3 / 4 / 5+ |
| 有多少时间 | 15 分钟 / 30 分钟 / 1 小时 / 不限 |
| 怎么吃 | 一道菜 / 一荤一素 / 一荤一素一汤 / 两荤一素一汤 |

底部是“颠勺！”按钮。条件会被记住。在 P1 长按 OK 可以跳过这一页，直接用上次的条件抽。

### P3 颠勺（约 1.6 秒）

NABO 颠锅（`toss`），程序画火苗和锅里飞起的光点。最后一下，一道菜（由程序把合成好的菜品图沿抛物线飞出）落到吧台上的盘子里，同时播放“滋啦”和落盘的声音。搭配模式下会连颠 2–3 下，每下落一道菜。

### P4 结果

- 菜品主图 160×120，放在吧台中央，上面飘着蒸汽（程序画）。
- 菜名用文楷 22 px。下面一行是标签：`25 分钟 · 家常 · 下饭`。
- 搭配模式下，三道菜横向排开，每道 72×54；用 UP 和 DOWN 选中一道，选中的那道放大。
- 底部是按键提示：`OK 开做`、`↓ 换一道（今天还剩 2 次）`、`双击↑ 返回`。
- NABO 端盘（`serve`），然后停在“请用”的姿势。
- 如果是 7 天内吃过的菜（只有放宽条件时才会出现），显示一个小标签“前天吃过”。

### P5 用料

- 主料：每行一个 32 px 图标，加上名称和用量，用量按人数换算。
- 调料：两列紧凑的文字。
- 按 DOWN 可以把整道菜的食材加进买菜单。按 OK 开始跟做。

### P6 跟做（最重要的一页）

```
┌──────────────────────────┐
│ 番茄炒蛋        步骤 3/6 │ 顶栏 24 px
│ [大火图标] [炒图标]       │ 图标行 32 px
│                          │
│  倒入蛋液，               │
│  等边缘凝固再推散，        │ 正文：黑体 18 px，每行 12 字，最多 5 行
│  七成熟盛出。              │
│                          │
│  小贴士：油要热透          │ 次要文字 14 px
│ ┌────────┐               │
│ │ ⏱ 0:30 │  NABO 小头像   │ 底部 64 px：计时胶囊加 40 px 头像
│ └────────┘               │
└──────────────────────────┘
```

- OK 下一步，UP 上一步；长按 DOWN 查看用料；双击 UP 返回（进度会保存）。
- 如果这一步带计时：进入这一步时，计时胶囊亮起；按 OK 开始计时。再按一次 OK 进入下一步，计时仍在后台运行。
- NABO 小头像会根据步骤变化表情：开始时是“加油”，有计时时“认真”，最后一步“期待”。
- 屏幕背景用深色纸纹，正文是浅色字，保证在厨房的强光下也能看清。

### P7 计时

- 中央一个大计时环（程序画），中间是剩余时间，用文楷 40 px 大字。下方列出其余计时器（最多 3 个），用 UP 和 DOWN 切换。
- 上方 NABO 守锅（`tend`），这是循环动画：看锅、扇扇子，偶尔偷尝一口（`taste`）。
- 时间到：NABO 敲锅（`ding`），播放铃声并重复 3 次，整个屏幕的边框闪烁。按 OK 停止。

### P8 上菜（完成）

NABO 竖起大拇指（`cheer`），一枚印章盖在菜名上，图鉴里这道菜点亮。如果升级了，接着播放升级动画（`levelup`），并显示新徽章。最后显示今天的小结：`今天做了 2 道 · 连续 5 天`。

### P9 冰箱：选食材

- 网格是 5 列 × 4 行，每格 48×48，里面放 40 px 的食材图标，分 4 页（肉、海鲜、蛋豆、蔬菜）。
- UP 和 DOWN 在格子间移动；OK 勾选，勾选后图标加一个绿勾和亮框；双击 UP 返回；长按 OK 进入推荐。
- 上方的 NABO 变成翻看食材的样子（`think`）。

### P10 推荐列表

每行一道菜，包括 48×36 的缩略图、菜名和一个标签：`齐了` 或 `缺 1 样：葱`。最多 10 道。OK 进入 P4。

### P11 买菜单

- 用纸条样式的清单，每行一个食材图标、名称和合并后的用量。OK 打勾，打勾的划掉并沉到底部。
- 菜单底部有“清空已买”。v0.2 再考虑“显示二维码，用手机带走”。

### P12 我的菜谱（图鉴）

- 一页 3×3 个格子，每格 72×54 的缩略图。做过的菜显示彩色；没做过的显示剪影和问号；收藏的菜角上有一颗星。
- 顶部显示等级徽章、累计道数和连续天数。
- 用 UP 和 DOWN 翻格子，OK 打开 P4，长按 OK 收藏或取消收藏。
- 筛选：全部 / 做过的 / 收藏 / 我存的（小智存进来的菜谱）。

### P13 设置

声音（开或关、音量）、每天重抽次数（1–5）、“不吃”的食材（例如香菜，抽菜时排除）、口味偏好（少辣、少油）、清空记录（要确认两次）。

## 5. 等级和收集

| 等级 | 条件 | 徽章 |
|---|---|---|
| 夜宵学徒 | 开始 | 木锅铲 |
| 深夜帮厨 | 做过 10 道不同的菜 | 铜勺 |
| 夜班主厨 | 做过 40 道，或者连续 14 天 | 银锅 |
| 深夜厨神 | 做过 100 道，并且连续 30 天 | 金色灯笼 |

只有**走完跟做全部步骤**才算做过一道菜，只看菜谱不算。同一道菜做第二次，算累计次数，但不算新解锁。

**每周挑战**：每周一抽一道还没做过的菜，作为“本周新菜”。做了就额外给一枚印章。

## 6. NABO 台词（示例，屏幕上的小气泡，不说话）

- 抽菜前：“今天想吃点热乎的？”、“冰箱里还剩啥？”
- 结果：“这道我拿手。”、“前天才吃过……算了，换一个？”
- 跟做时：“油热了再下。”、“别急，等它自己定型。”
- 计时到：“好了好了！”
- 完成：“吃饭了！”、“今天辛苦了。”
- 深夜（23 点以后）：“夜宵别太油哦。”

台词表放在 `data/lines.json`，按场景随机挑选，每个场景至少 5 条，同一条不会连续出现。
