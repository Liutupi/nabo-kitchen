# 界面样板

用浏览器打开 `index.html` 即可，渲染结果就是上一级目录的 `ui-mockup.png`。

- `art.js` 里的菜品和食材是 Claude 用 SVG 画的**占位图**，只用来定版式和气质，正式素材由 Codex 按 ART_BRIEF 画。
- `nabo.png` 借用的是 NABO 工具箱的起始图 `S0_base.png`（已抠掉绿幕），厨房造型定稿后再替换。
- `archivo-black-latin-400-normal.woff2` 是 Archivo Black 字体（SIL OFL 1.1，来自 @fontsource/archivo-black）。
