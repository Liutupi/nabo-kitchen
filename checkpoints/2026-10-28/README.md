按刘东坡要求固定当前成果，供另一台电脑或助手继续开发。本检查点为宿主机工程候选资源，未发布固件。对应 Git 标签 `checkpoint-2026-10-28`；当前决定与待办见根目录 `HANDOFF.md` 顶部。

## 保存范围

- `packages/`：KSP1 三个静态池、KAN1 四动作动画、KRC1 菜谱库和 KFN1 点阵字体，及字体许可/字符清单。`review_static.ksp` 只用于造型/样板审图，不是运行时资源。
- `reports/`：实际大小、源哈希、索引色/往返验证、字形覆盖和构建确定性。
- `proofs/`：解码后 30 道菜的深浅底合成、动画抽帧深浅底与字库检查图。
- `validation/`：本次宿主检查命令、退出码与测试输出。原型最终报告和页面截图保存在 `prototype/validation/`。
- `manifest.json`：每个检查点文件和对应源码输入的字节数/SHA-256。UTF-8 文本统一按 LF 换行计算，二进制逐字节计算，避免不同电脑的 Git 换行设置影响校验。清单不含自身，也不含被忽略的私有缓存。

源码、172 张静态清单图片及同名记录、四段选中 MP4、原型和字体子集在正常仓库目录中保存；此前的美术提交仍保留在 Git 历史。按协作规则，`private/` 的设备/环境/大图草稿、完整源字体、官方字表 PDF、逐帧缓存和依赖不上传。快照不依赖这些缓存才能查看，重建字体可以按固定哈希重新下载。

## 验证与运行

```powershell
python tools/verify_checkpoint.py
python tools/verify_checkpoint.py --sources
node prototype/server.mjs
```

第二条检查当前源码是否仍与冻结时一致；后续有意修改源码后不匹配是正常的。原型访问 `http://127.0.0.1:4173/`，默认静音。测试与重建分别见 `prototype/README.md`、`tools/FORMAT.md`、`tools/ANIMATION_FORMAT.md`、`tools/FONT_FORMAT.md`。动画 SHA 绑定的审查输入在 `tools/validation/animation-source-review.json`，FFmpeg/FFprobe 使用本机可用程序，精确选择帧参数见动画报告。

## 已知限制

当前六个运行时包合计 **1,686,754 字节**，不含招牌菜精绘、音效、小智基线资产及容器开销。这个小计低于约 1.8 MB 的早期厨房估算，不能证明实际固件 Flash 放得下。字体独占 **959,955 字节**，超过 **380,000 字节**分项预算，必须继续优化或由架构复核分配，定稿规格没有被改写。

PNG/视频经过缩小、抠绿、RGB565 限色后有损；往返逐像素一致是指打包前后的索引图。四动作候选包使用 192×192 帧；源 CSV 的 `256x256 frames` 标注及 ART_BRIEF 对应要求需在接入 C 前由架构/美术复核，不能将候选实现直接视为规格验收。原型仍使用静态 C/K2，尚未播放该动画包。30 个菜名通过不代表 30 道做法已经实做验收。C 对拍、C 渲染、固件仓库、构建/刷机、真机内存/按键/音频和家庭一周验收均未完成。
