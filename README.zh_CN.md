# AI Passport 的 NABO 深夜厨房

当前保存状态、工牌实际版本和未完成事项见[离线厨房交接](docs/development/offline-kitchen-handoff.zh_CN.md)。

这是 FoloToy AI Passport 工牌（ESP32-C3、8 MiB Flash、无 PSRAM）的独立离线厨房。开机播放 NABO 动画和本地欢迎语，之后停留在开机画面，短按 OK 进入厨房。本版本不包含联网、云端对话或语音识别。

当前候选包含 144 道家常菜草案、完整菜图草案、分层菜品画面、角色动画、冰箱和买菜单、收藏、跟做进度以及最多三个独立计时器。菜谱做法仍待家庭厨房实做审核；部分菜复用近似菜图，新菜缺少完整图时会显示占位。新图标、菜图和动作变体仍是待审素材。

模型最多支持 192 道菜。超过 64 道时，多菜搭配使用有上限的随机候选池，权重和软条件放宽结果可能与全库穷举不同。食材忌口不筛查调料、过敏原或交叉接触。极限满载记录虽可编码，但两份记录可能超过现有 NVS 空间；满载设备保存仍未验证。

## 操作和日期

开机画面短按 OK 进入；如有待处理的计时提醒，OK 会先打开提醒。其他页面上、下键移动，OK 确认，双击上返回，长按上回厨房首页。首页长按 OK 抽菜；首页长按下进入手动日期设置。在日期页面用上、下调整当前项，OK 依次选择年、月、日并确认，双击上取消。

抽菜结果页按下键可以不限次数地换菜。计时页用上、下键选择计时器，长按 OK 暂停或继续，长按下键取消当前计时器。取消步骤计时后，再回到该步骤不会自动重新启动它。

冰箱里先用上、下键选择肉、海鲜、蛋豆、蔬菜或主食，再按 OK 进入该类；选择食材后按 OK 勾选。双击上返回品类，再双击上返回上一页；长按 OK 查看冰箱推荐。推荐优先列出主料齐全的菜；缺一项时至少需要已有另一项主料。

日期不是自动更新的时钟：重启后需要重新确认，日期变化时需手动调整。未确认日期时，程序不会把季节、最近几天和连续天数当成可靠信息；做菜仍计入累计数量。运行中的计时器遇到断电后会恢复为暂停并提示。开机语音、计时铃和动画均在本机播放。

## 构建和验证

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`。完整门禁包括仓库与宿主测试、独立目标构建、合并镜像校验及配套调试归档。修改 `assets/kitchen` 中的六个源资源后，先运行 `python3 tools/pack_kitchen_assets.py` 重建可复现的资源包，再构建固件。菜谱和美术源项目单独维护。

当前候选采用产品专用分区：NVS 与 PHY 保持原地址，factory 应用占 `0x10000..0x1fffff`，只读厨房资源占 `0x200000..0x6fffff`，已有 `files` 区保留在 `0x700000..0x7fffff`。刷机前必须明确确认分区表和 bootloader 的变化。合并镜像会填充空隙并可能覆盖 NVS；需要保留已有数据时，应经用户授权后分段写入。无需整片擦除或备份原有固件。

构建成功不代表实机验收。屏幕、实体按键、开机语音、油烟机旁计时铃、三个并行计时器、断电恢复和实际动画速度仍需在工牌上测试。硬件与开发资料见 [docs/README.zh_CN.md](docs/README.zh_CN.md)。
